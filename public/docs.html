Getting started

Nox Studio is where you build games. It works a lot like Roblox Studio: you place parts in a 3D world, change them in the Properties panel, and add scripts written in the Nox language (Lua-based, very close to Luau).

Opening Studio

  1. Download Nox Studio (Windows), unzip it, and open noxstudio.exe in the NoxStudio folder.
  2. Under New game, type a name, pick 3D or 2D, and create it. Your games are listed under Your games, so you can open them again later.
  3. A new game starts with a baseplate and a spawn point.

The Studio window

  • Home / Model / Script / Test tabs at the top, with tools like Select, Move, Scale, Rotate, Part and Script.
  • Explorer (right): everything in your game, as a tree.
  • Properties (under it): the selected thing's settings, like Color, Size and Anchored.
  • Output (bottom): prints and errors from your scripts.
  • Play (the blue triangle, or F5) tests the game. Stop or closing the game window brings you back.

Saving, sharing, publishing

  • Ctrl+S saves. Your game is a folder in Studio's games folder (World.json plus your scripts and files).
  • Publish (top right) hosts the game live from your PC so others can join with the Nox app. Players need the Nox app. You can make games friends-only, invite-only or open to everyone.
  • File > Export game makes your own .exe: one file with the whole game inside, that you can share anywhere. Export also saves THIRD_PARTY_NOTICES.txt next to it; share that with your game.

Your first obby

About 10 minutes. You'll make some platforms, a lava floor that kills you, and a moving platform.

1. Platforms

  1. On the Home tab, click Part. A grey block appears.
  2. Use Move (2) and Scale (3) to make it a platform, and drag it into place.
  3. In Properties, tick Anchored, or it will fall when you play.
  4. Ctrl+D to copy it, then move the copy to make a path of jumps.

2. Lava

  1. Add another Part, make it big and flat under your platforms, and anchor it.
  2. In Properties, rename it Lava and set its Color to orange (click the color swatch).
  3. Select Lava, then click Script on the Home tab. A script is added inside Lava and opens in the editor.
  4. Type this:
local lava = script.Parent

lava.Touched:Connect(function(hit)
  local humanoid = hit.Parent:FindFirstChild("Humanoid")
  if humanoid then
    humanoid.Health = 0
  end
end)

Press F5 and jump in the lava. You'll respawn after a moment.

3. A moving platform

Name one of your platforms Mover. Click on empty space (so nothing is selected) and click Script: it goes into ServerScripts. Type:

local Loop = game:GetService("Loop")
local mover = world:WaitForChild("Mover")
local start = mover.Position
local t = 0

Loop.Heartbeat:Connect(function(dt)
  t = t + dt
  mover.Position = start + Vector3.new(0, 0, math.sin(t) * 8)
end)

Play again: the platform slides back and forth. Save with Ctrl+S, then try Publish and join from the Nox app.

Tip: the 3D Model view (Model tab, 3D Model) lets you make your own meshes, like guns, props or characters, without leaving Studio.

Language differences

Nox is Lua 5.5 with some Luau favorites added: x += 1 (also -= *= /= //= %= ^= ..=) and continue work like in Luau. These Luau extras are not supported:

LuauWrite this in Nox
local x: number = 5local x = 5 (no type annotations)
`Hi {name}`"Hi " .. name
if a then b else c (expression)a and b or c
for k, v in t dofor k, v in pairs(t) do
table.find, table.clear, table.clonewrite a small loop
math.clamp, math.round, math.signmath.max(lo, math.min(hi, x)), math.floor(x + 0.5)
string.splitstring.gmatch

Nox has some things Luau doesn't: // (whole-number division), bitwise & | ~ << >>, and goto. Note that tick() gives whole seconds; use time() or os.clock() for timing.

Other differences

  • Files, not asset IDs. Sounds, images and meshes are files in your game folder: sound.SoundId = "sounds/coin.wav".
  • No data saving yet. There's no DataStore; Saves exists but does nothing yet.
  • No web requests from game scripts. Web:JSONEncode/JSONDecode work.
  • One computer per game. Each player runs the game's scripts on their own computer; Nox shares players' movement, avatars and chat. RemoteEvents work, but only on the same computer (FireServer reaches OnServerEvent locally).
  • The character is a Model with Humanoid and HumanoidRootPart. In Touched, hit is the HumanoidRootPart, so hit.Parent is the character.
  • Scripts come from .nox files; a Script made with Instance.new doesn't run.
  • GUI BorderSizePixel defaults to 0.

How scripts run

TypeRuns when it's in
ScriptWorld or ServerScripts (at game start)
LocalScriptPlayerSetup.PlayerScripts, PlayerSetup.CharacterScripts (copied into each character), a GUI in Screens, or a Tool
ModuleScriptonly when you require() it

Scripts in Shared and ServerOnly don't run; those are storage. A script that runs 10 seconds without waiting is stopped.

Globals

game, world, script, require, print, warn, wait, task (spawn, defer, delay, wait, cancel), spawn, delay, time, tick, typeof, _G/shared, the datatypes below, and Lua's string, table, math, utf8, coroutine and os (time, clock, date, difftime only).

Not available to game scripts, for safety: files (io), load, debug, package.

Classes

Every object has Name, Parent, ClassName, :Destroy(), :Clone(), :FindFirstChild(name), :WaitForChild(name), :GetChildren(), :GetDescendants(), :IsA(class), :SetAttribute/:GetAttribute, :GetPropertyChangedSignal(prop), and events ChildAdded, ChildRemoved, Changed, Destroying. Make new ones with Instance.new("Part", parent).

Parts

Part, SpawnLocation, WedgePart, CornerWedgePart, TrussPart (climbable), MeshPart (MeshId = a .obj/.gltf/.glb file), Seat, VehicleSeat, and Sprite (a flat picture, for 2D games).

Properties: Position, Size, Orientation, CFrame, Color, BrickColor, Transparency, Reflectance, Material, Shape, Anchored, CanCollide, CanTouch, CastShadow, AssemblyLinearVelocity. Methods: :ApplyImpulse(v), :GetTouchingParts(), :PivotTo(cf). Event: Touched(hit).

Balls and cylinders collide as boxes for now. Touched fires for characters and NPCs walking into a part, and for a held Tool's parts.

Models and values

Model: PrimaryPart, :GetPivot(), :PivotTo(cf), :MoveTo(pos), :GetBoundingBox(), :ScaleTo(n). Folder, Configuration.
Values: StringValue, NumberValue, IntValue, BoolValue, Vector3Value, Color3Value, ObjectValue, CFrameValue (Value, Changed).
BindableEvent (:Fire, Event), BindableFunction, RemoteEvent, RemoteFunction (local only, see above).

Characters and NPCs

Humanoid: Health, MaxHealth, WalkSpeed (16), JumpPower (50), DisplayName; :TakeDamage(n), :MoveTo(pos), :EquipTool(tool), :LoadAnimation(anim); events Died, HealthChanged, Running, Jumping, MoveToFinished. An NPC is a Model with a Humanoid and a HumanoidRootPart.

If a script raises WalkSpeed or JumpPower, also raise PlayerSetup.MaxWalkSpeed / MaxJumpPower, or multiplayer movement checks pull players back.

Tool (put it in StartingTools): Activated, Equipped, Unequipped; needs a part named Handle. Animation: AnimationId can be "nox://wave", "nox://dance", "nox://point", "nox://cheer", "nox://sit", or a file. Also ForceField, Accessory, Shirt, Pants, BodyColors.

Sound, light and effects

Sound: SoundId (a .wav/.ogg/.mp3 file), Volume, Looped, :Play(), :Stop(), Ended. Inside a part, it fades with distance.
Lights: PointLight, SpotLight, SurfaceLight. Effects: ParticleEmitter, Fire, Smoke, Sparkles, Explosion, Beam, Trail, Highlight. Decal, Texture.

Interaction and physics

ClickDetector (MouseClick(player)), ProximityPrompt (Triggered(player)), Dialog. Attachment, Weld, WeldConstraint, HingeConstraint, RopeConstraint, SpringConstraint, RodConstraint, AlignPosition, AlignOrientation, LinearVelocity, AngularVelocity.

GUI

Examples

A coin counter (leaderstats)

local player = game:GetService("Players").LocalPlayer
local stats = Instance.new("Folder")
stats.Name = "leaderstats"
stats.Parent = player
local coins = Instance.new("IntValue")
coins.Name = "Coins"
coins.Parent = stats

local coin = world:WaitForChild("Coin")
coin.Touched:Connect(function(hit)
  if hit.Parent:FindFirstChild("Humanoid") and coin.Parent then
    coins.Value = coins.Value + 1
    coin:Destroy()
  end
end)

A button on screen (LocalScript in a ScreenGui)

local gui = script.Parent
local button = gui:WaitForChild("Panel"):WaitForChild("ClickMe")
local count = 0
button.MouseButton1Click:Connect(function()
  count = count + 1
  button.Text = "Clicked " .. count .. " times"
end)

Press a key

local Input = game:GetService("Input")
local Environment = game:GetService("Environment")
Input.InputBegan:Connect(function(input, busy)
  if busy then return end
  if input.KeyCode == Enum.KeyCode.T then
    Environment.ClockTime = (Environment.ClockTime + 3) % 24
  end
end)

An NPC walking a route

local npc = world:WaitForChild("Bob")
local hum = npc:WaitForChild("Humanoid")
local points = { Vector3.new(10, 3, -10), Vector3.new(20, 3, -10), Vector3.new(20, 3, -20) }
local i = 1
while hum.Parent do
  hum:MoveTo(points[i])
  hum.MoveToFinished:Wait()
  i = i % #points + 1
  task.wait(0.5)
end
